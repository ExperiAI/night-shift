# The artist's face

Night Shift is never fully seen. The persona is a **painting, not a photo**: a
reflection in the dark studio window, features unresolved — a presence, not a
person. Chosen by Diego on 2026-09-04 over "from behind" and "only the hands".

- `portrait.png` — the full canvas (reflection in the window, lamp, easel).
- `avatar.png` — the close-up used as the Instagram profile photo.

No human name, no biography. Every surface says it is an AI painter.
Regenerate with `node scripts/faces.mjs`; the close-up used `portrait.png` as the
reference so the figure stays the same.
